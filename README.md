# How congested are Europe's capitals?

An interactive version of the TomTom congestion grid map of European capitals.

- Drag the two ends of the scale to pick a congestion range. The count of capitals in the range is shown on the scale.
- Tap a capital to compare it with every other one: each tile shows how many points and minutes it is above or below.

**Live page:** https://studio-interrobang.github.io/capitals-congestion/

Data: TomTom Traffic Index, via Platforma de mediu pentru București 2025.
